Stock Counter reads and writes the same Firestore catalog collection as Inflow and Barcode Maker. Each adjustment is applied against the very latest stock value at the moment it's saved, so it's safe even if someone else is counting at the same time. If you're offline, adjustments are queued on this device and applied automatically once you're back online.

Camera scanning needs this page loaded over https:// (or http://localhost) — opening the HTML file directly won't allow camera access. Host it on any secure web server and the Scan Barcode button will work.
